Project Overview / Concept

This project was a deep dive into procedural generation using Blender's Geometry Nodes. The goal was to create an infinite, looping animation of a hyperspace jump, similar to classic Sci-Fi, but with a unique visual twist.

*Final render, aspect ratio 16:9, rendered in Eevee.*

Technical Breakdown / Stack

Key Tools Used:

  • 3D & Motion: Blender 4.1 (Geometry Nodes, Cycles/Eevee)
  • Compositing: Adobe After Effects for final color grading and film grain overlay.
  • Assets: Custom textures created in Adobe Illustrator.

Lessons Learned

The biggest challenge was optimizing the Geometry Node tree for render speed while maintaining visual complexity. This led to a better understanding of **instancing efficiency** and **GPU utilization**.
