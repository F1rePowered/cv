    Short Summary

    This project represents a Trellis-board based Arduino-powered MIDI board. It can be used to bind keys, play rythm video games or simply depict a lit up pattern, once connected to an USB-A capable device.

    Components

      x4 M3 10mm screws
      x4 Trellis Boards
      x4 Silicon Button Pads
      Arduino Uno
      x32 LEDs
      x1 I2C LED Screen
      x1 PIR Motion Sensor
      x1 3D Printed Case

    Methodology

    I started with comprehensive research into technical requirements and component specifications necessary.

    The MIDI board utilizes a custom 3D-printed modular case designed specifically for the button mesh dimensions, with precise internal clearances for the Arduino and Trellis boards, and integrated cable routing for the I2C display.


    The device features a PIR motion sensor for proximity-based security, an interactive I2C display that responds to button inputs, and 32 individually manageable LEDs positioned beneath each button.


    Its code can be accessed here for those interested.

    Short Summary

    This ukulele offers the user the opportunity to play alongside a backing track without the need to carry around external devices.
    It has an integrated 4 ohm speaker that can play backing tracks read off of an SD Card Reader integrated inside of the Ukulele.

    Components

      x1 DF Mini Player SD Reader
      x1 Amplifier + Potentiometer
      x1 4 Ohm speaker
      Arduino Nano

    Methodology

    I began this project by researching the details of ukulele acoustics and what materials and practices would be best to use in order to retain proper sound accuracy.


    This project was made out of lasercut wood, after a "Cigar-box" Ukulele structure. Wood-glue was used to retain the acoustics, this unfortunately denying the opportunity of a modular design.


    The speaker and potentiometer had accurately cut entries on the top frame so that they would properly fit. Hot glue was used to mount some of these components. Electrical tape was used on the cables in order to reduce electrical interference.
